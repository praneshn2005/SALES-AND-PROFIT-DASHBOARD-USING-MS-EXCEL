📌 Project Overview

This project presents an interactive Sales and Profit Dashboard built using Microsoft Excel. The dashboard converts raw sales data into meaningful insights to help understand business performance and support data-driven decisions.

🎯 Objectives

Analyze overall sales and profit performance

Identify top and low performing regions and product categories

Track time-based sales and profit trends

Highlight profitability gaps despite high sales

🛠 Tools & Techniques Used

Microsoft Excel

Pivot Tables & Pivot Charts

Excel formulas (SUMIFS, IF, etc.)

Slicers and filters for interactivity

Data cleaning and formatting

📈 Key Features

KPI metrics for total sales and profit

Category-wise and region-wise analysis

Trend analysis using charts

Interactive filtering for dynamic insights

📂 Files Included

Sales and Profit Dashboard.xlsx – Excel dashboard file

Sales and Profit Dashboard Data.xlsx – Raw dataset used for analysis
